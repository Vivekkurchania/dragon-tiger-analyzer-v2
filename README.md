# Dragon Tiger Bluetooth Analyzer v2

Two Android apps:
- Sender: scan the Analyzer QR, connect over Bluetooth, and send D/T test results.
- Analyzer: displays its Bluetooth QR and receives the latest 100 results.

QR payload identifies the Analyzer Bluetooth name/address. Android still requires normal Bluetooth pairing/permissions; QR does not bypass Android security.

The analyzer provides a statistical estimate from the latest 100 recorded results. It cannot guarantee or determine a random/RNG game outcome.
